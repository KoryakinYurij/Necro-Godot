# Build the trial around Exploration, not Arena survival

Necro's target identity is an Exploration / Action Roguelite where the player chooses direction, local opportunities, risks, fights, and POIs inside an Expedition.

The Godot trial exists to test that direction. It must not recreate the legacy time-driven Arena loop as a prerequisite or use automatic global waves to make the prototype feel active.

## Consequences

- Space and player choice trigger meaningful combat.
- Local Encounters and POIs are first-class gameplay concepts.
- Quiet traversal is allowed, but the trial must eventually prove that exploration does not become dead walking.
- Legacy Arena behavior is reference/history, not Godot scope.
