# Triage Labels

| Matt role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for information or a blocking decision |
| `ready-for-agent` | `ready-for-agent` | Self-contained and ready for an implementation agent |
| `ready-for-human` | `ready-for-human` | Requires human judgement/action |
| `wontfix` | `wontfix` | Will not be actioned |

Use the GitHub labels on the right whenever a Matt skill refers to the canonical role on the left.
