# Godot Exploration Trial

The trial advances through evidence gates rather than by porting the old backlog.

## Gates

- **G0 — Contract:** engine/version, target/export platform, test-device policy, representative load, acceptance evidence, and minimal project boundaries are agreed.
- **G1 — Combat:** one exported build proves hero movement/camera, an enemy, an autonomous minion, damage, death, and clean restart.
- **G2 — Exploration:** a local Encounter supports activation, retreat/return, final clear, Ruins, one-time reward choice, and correct pause/modal behavior.
- **G3 — Suitability:** representative saturated combat, a small content variation, measurements, and a human playtest answer whether Godot should continue.

## Gate rule

Passing a gate means the evidence for that gate is accepted. It does not authorize unrelated legacy migration or future content.

Current details and blockers live in GitHub Issues.
